### 7.3 pywebview 6.2.1 源码

`.tools/pywebview-6.2.1-webview/`（从 wheel 解包）。**API 以它为准**，关键点：

- `create_window(title, url, js_api=..., width=, height=, min_size=(w,h), background_color=, hidden=, text_select=, confirm_close=)`
- `webview.start(debug=, http_server=True, private_mode=True)`；`http_server=True` 时本地 `index.html` 由内置 Bottle 服务（随机端口），**不用自己写静态服务器**
- `webview.FileDialog.FOLDER / OPEN / SAVE`（`OPEN_DIALOG` 等常量已废弃）
- `window.dom.document.events.drop/dragenter/dragover += DOMEventHandler(fn, prevent_default=, stop_propagation=)`；drop 事件里 `files[i]["pywebviewFullPath"]` 由 `webview/util.py:299` 注入
- `webview.settings["ALLOW_FILE_URLS"]`、`WEBVIEW2_RUNTIME_PATH`、`DRAG_REGION_SELECTOR`
- `window.evaluate_js(js)` 是 Py→JS 唯一通道（EventPump 独占）

## 9. 本机做不了的事（必须靠 CI / Windows）

1. **真实 WebView2 渲染**：Linux 上 pywebview 走 GTK/WebKit，与交付形态不同 → 真实效果只认 Windows CI。
2. **exe 打包**：PyInstaller 只能在本机做 Linux 产物。
3. **DPI / 多屏 / IME**：需要 Windows。
4. 本地能覆盖的：Python 单测、TS 类型、`vite build`、Chromium 截图/交互（Playwright 注入假桥）。
